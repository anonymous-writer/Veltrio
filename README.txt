# Veltrio Icon Set

Generated from the Veltrio app-icon artwork.

## Files
- `icon.svg` — scalable SVG container with embedded 1024px artwork
- `icon-1024.png` — master raster artwork
- `icon-512.png`, `icon-256.png`, `icon-128.png`, `icon-64.png`, `icon-48.png`, `icon-32.png`, `icon-16.png` — common application sizes
- `icon-512-circle.png` — circular variant
- `icon-symbol.png` — download emblem without the wordmark, transparent background

The SVG embeds its PNG artwork, so it is self-contained and does not depend on a separate image file.
